# International Students Mental Health Analysis

## Overview
This project explores whether studying abroad affects the mental health of international university students in Japan. The analysis is based on survey data collected in 2018 and focuses on factors such as social connectedness, acculturative stress, and length of stay.

## Objective
Using PostgreSQL, this project investigates:
- Whether international students show higher risks of depression
- The relationship between social connectedness and mental health
- Whether acculturative stress contributes to depression
- If length of stay affects mental health outcomes

## Tools Used
- PostgreSQL
- SQL
- Jupyter Notebook

## Dataset
The dataset contains survey responses from international university students in Japan, including:
- Depression indicators
- Social connectedness scores
- Acculturative stress scores
- Length of stay

## Analysis Performed
- Data exploration
- Statistical summaries
- Correlation analysis
- SQL aggregations and filtering
